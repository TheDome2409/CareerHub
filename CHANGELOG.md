# Changelog

All notable changes to CareerHub will be documented in this file.

This project follows the spirit of [Keep a Changelog](https://keepachangelog.com/)
and will use semantic versioning once the public API stabilizes.

## [Unreleased]

### Added

- CareerHub MVP+ Streamlit prototype.
- CompanyHub foundation with company sources, documents, evidence and knowledge drafts.
- Persistent Skill Registry V1 with SQLite persistence, alias merge, conflict handling and review queue integration.
- Human-in-the-loop unknown skill review queue.
- Local Ollama integration for optional LLM-assisted workflows.
- OCR/PDF/document processing foundations.
- Job matching, company matching foundations and application package generation.
- OpenLLMBench foundation and local benchmark runner foundations.
