# CareerHub v0.1.0 - Initial Public Portfolio Release

Status: **Prepared release notes**

CareerHub v0.1.0 is the first public portfolio release candidate. It publishes a
single-history, public-safe snapshot of a local-first career matching and
application workflow prototype.

## Purpose

This release demonstrates a transparent local workflow for:

- profile and skill analysis
- job matching
- human-reviewed unknown skills
- persistent skill knowledge
- company evidence foundations
- application-package generation
- optional local LLM assistance

It is not a production recruiting platform or SaaS service.

## Highlights

- **Persistent Skill Registry V1**: approved unknown skill candidates can create
  or update persistent SQLite skill entries, including alias merge and type
  conflict handling.
- **Human-in-the-Loop Review Queue**: LLM-evaluated candidates remain
  suggestions until explicitly reviewed.
- **Job Matching**: deterministic score components for role, work model, salary,
  career, employer, skill, competency and role mismatch.
- **CompanyHub Foundation**: tracked companies, sources, fetched documents,
  evidence extraction, canonical company concepts, knowledge drafts and pipeline
  inspection.
- **Company Profile Match Foundation**: mission, domain, technology, work-model,
  KRITIS and exclusion dimensions.
- **Local LLM Integration**: optional Ollama workflows for skill candidate
  evaluation, application text and company knowledge draft review.
- **OCR/PDF Foundations**: PDF text extraction and optional OCR path through
  Tesseract/Poppler.
- **Application Package**: HTML and ZIP export plus full PDF generation when a
  real HTML-to-PDF renderer is installed.
- **OpenLLMBench Foundation**: experimental local benchmark runner and framework
  skeleton for future model evaluation workflows.
- **Synthetic Examples**: public-safe example profile, job posting and company
  profile material.
- **Product Documentation**: product vision, product journey, product-owner case
  study, backlog and ADRs documenting key decisions.

## Known Limitations

- Final PDF export depends on local renderer setup (`wkhtmltopdf/pdfkit` or
  WeasyPrint).
- OCR depends on local Tesseract and Poppler availability.
- Live job sources depend on external endpoints and configuration.
- CompanyHub does not include a production crawler, scheduler or automated
  research agent.
- OpenLLMBench is an experimental foundation, not a stable standalone package.
- LLM-generated text always requires human review.
- Product-owner documentation describes the v0.1.0 project process; it does not
  imply production adoption, user metrics or business outcomes.

## Privacy And Security Notes

- The public repository should contain only code, configuration examples,
  synthetic demo material and tests.
- Runtime databases, review queues, uploads, generated application packages and
  benchmark outputs are intentionally ignored.
- `.env.example` contains placeholders only.
- Users are responsible for the privacy and license terms of local data, local
  tools and local model files they use.

## Optional System Dependencies

- Ollama and a locally installed model for LLM workflows.
- Tesseract and Poppler for OCR.
- wkhtmltopdf or WeasyPrint for automatic final PDF package generation.
- DuckDB if optional benchmark archive functionality is enabled.
