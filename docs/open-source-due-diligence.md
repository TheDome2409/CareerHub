# Open-Source Due Diligence

Status: **In progress**

CareerHub is prepared as a public portfolio release from a private development
repository. This note tracks publication due diligence and known limits.

## Project Origin

CareerHub was developed as an AI-assisted local prototype for career matching,
company analysis foundations, document processing and application package
generation. The public candidate is exported from a single approved private
commit without private Git history.

## AI-Assisted Development

Parts of the code and documentation were created with AI assistance and reviewed
through local tests, documentation audits and privacy scans. AI assistance does
not remove the need for human review.

## Code Provenance

No intentional copy of a complete third-party codebase is included. The project
uses ordinary Python dependencies via `requirements.txt`; those packages remain
third-party software under their own licenses.

## Dependency License Review

A detailed dependency license inventory is still pending. `THIRD_PARTY_NOTICES.md`
currently records this as in progress rather than complete.

## Name and Trademark Review

The project name CareerHub is used as a descriptive portfolio project name. A
formal trademark clearance has not been performed.

## Related Work

CareerHub touches areas such as job matching, resume/application assistance,
local LLM workflows, PDF/OCR processing and benchmarking. A systematic related
work or prior-art review has not been completed.

## Assets and Data

The public candidate should contain only source code, configuration examples,
synthetic examples and tests. Runtime databases, benchmark outputs, uploads,
exports, real resumes, applications, certificates and private company documents
must not be committed.

## Patent / Prior Art

No patent clearance has been performed. Any review is best-effort and limited.

This document is not legal advice and does not claim full legal certainty.
