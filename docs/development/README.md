# Development Log

Every larger development effort should receive its own Markdown document in
this directory.

Recommended format:

```markdown
# YYYY-MM-DD - Title

## Date

YYYY-MM-DD

## Goal

What should this development step achieve?

## Implementation

What changed?

## Problems

What was difficult or unexpected?

## Decisions

Which design decisions were made?

## Open Points

What remains unresolved?
```

The development log is not a replacement for ADRs. Use ADRs for architecture
decisions with long-term impact.
