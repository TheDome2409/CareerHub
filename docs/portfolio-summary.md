# Portfolio Summary

CareerHub demonstrates practical work across local AI tooling, document processing, explainable matching and product-oriented workflow design.

## Demonstrated Capabilities

- **Implemented**: Python service architecture with Pydantic models, repository abstractions and Streamlit UI.
- **Implemented**: configurable job matching with explainable score components.
- **Implemented**: human-in-the-loop workflow for unknown skill candidates.
- **Implemented**: local Ollama integration for application text and structured review tasks.
- **Implemented**: application package generation with HTML, ZIP and renderer-dependent final PDF.
- **Implemented**: CompanyHub foundation with SQLite, source management, document fetching, evidence extraction and knowledge drafts.
- **Implemented**: tests for scoring, skill workflows, CompanyHub foundations, application export and benchmark foundations.
- **Partially implemented**: OCR and scanned PDF handling.
- **Experimental**: OpenLLMBench and local model benchmarking foundations.

## Product Thinking

CareerHub is built around a clear product thesis: career decisions need structure, explainability and human judgment, not only generated text.

The project shows:

- separation of deterministic logic and generative AI
- care for privacy and local processing
- review workflows instead of automatic taxonomy mutation
- transparent score components
- realistic handling of partial data and config fallbacks
- incremental expansion from job matching to company intelligence

## Boundaries

CareerHub is not production SaaS. It is a local prototype and portfolio project. Some parts are mature enough for local demo use; others are foundations for future work.

The strongest current demo paths are:

- profile and skill review
- job matching with score explainability
- application package generation
- CompanyHub evidence and knowledge draft pipeline
