## Why AGPLv3?

CareerHub is a local-first portfolio and learning project that handles sensitive
career and application workflows. AGPLv3 keeps the source code available when the
software is modified and offered over a network. This fits the project goal of
keeping matching, document generation and model-assisted workflows transparent
and inspectable.

## Network Copyleft Notice

AGPLv3 contains obligations for modified versions that are made available for use
over a network. If you deploy a modified CareerHub instance for others, review
the license terms carefully.
