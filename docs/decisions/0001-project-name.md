# ADR 0001: Project Name

## Status

Accepted

## Context

The benchmark work started inside CareerHub, but the benchmark concepts are not
specific to career matching. The framework should support coding,
documentation, architecture, security, UE5, OpenSky and other domains.

## Decision

Use the name **OpenLLMBench** for the future standalone framework.

## Alternatives

- Keep the name CareerHub Benchmark.
- Use a generic name such as LocalLLMBench.
- Use a product-style name unrelated to benchmarking.

## Consequences

OpenLLMBench communicates the scope clearly: open, LLM-focused and benchmark
oriented. CareerHub can become one suite rather than the identity of the whole
framework.
