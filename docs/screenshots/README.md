# Screenshot Plan

Status: **Planned**

This directory is reserved for future public screenshots. No screenshots are
included in the initial repository until they have been reviewed for privacy and
public-safety.

## Use Only Synthetic Data

Screenshots should use:

- `examples/synthetic_profile/`
- `examples/synthetic_job_posting/`
- `examples/synthetic_company_profile/`
- public-safe company profiles under `data/company_profiles/`

Do not capture real names, addresses, phone numbers, e-mail addresses,
certificates, resumes, generated letters based on private material, local paths
or review queue entries from real usage.

## Recommended Screenshot Order

1. `01-dashboard.png` - Streamlit entry page or tab overview.
2. `02-profile-analysis.png` - synthetic profile skills and preferences.
3. `03-job-matching.png` - job score components with synthetic jobs.
4. `04-review-queue.png` - Human-in-the-Loop skill review using synthetic terms.
5. `05-skill-registry.png` - persistent registry view or workflow.
6. `06-companyhub.png` - tracked company, sources and pipeline inspector.
7. `07-application-package.png` - generated package preview with synthetic data.

## Privacy Checklist Before Publishing

- No personal names or contact details.
- No local Windows, macOS or Linux user paths.
- No real employer notes or private company documents.
- No API keys or tokens in browser/sidebar/debug output.
- No real generated cover letters or resumes.
- No private uploaded filenames.

## README Usage

Only add image links to the main README after the screenshot files exist. Avoid
broken image placeholders in the public repository.
