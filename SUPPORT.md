# Support

CareerHub is a portfolio and learning project, not a production HR product.

Support is provided on a best-effort basis through repository issues once the
project is published. Good issue reports include:

- the command or UI action that failed
- a minimal synthetic example
- expected behavior
- actual behavior
- relevant traceback excerpts without secrets or personal data

Please do not upload real resumes, applications, certificates, API keys,
databases or private company documents.

CareerHub must not be used to automate legal, career, recruiting or personnel
decisions without human review. Generated application text and matching output
are assistance only.
