# Third-Party Notices

Status: **In progress**

CareerHub depends on third-party Python packages and optional local tools. Those
dependencies retain their own licenses and notices.

A full dependency-by-dependency license review has not yet been completed for the
initial public portfolio candidate. Do not treat this file as a complete legal
notice inventory.

Planned follow-up work:

- generate a dependency license inventory from the final lock/install set
- verify optional OCR, PDF and local LLM tooling licenses
- document any packages that require attribution notices
- keep generated notices separate from project-owned source code

This document is not legal advice.
