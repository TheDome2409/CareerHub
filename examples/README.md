# Synthetic Demo Data

All files in this folder are fully synthetic.

They do not describe a real person, a real company, a real job posting or a real
application. They are intentionally small examples for demonstrating CareerHub
workflows without exposing private application data.

Included workflows:

- profile analysis
- job posting analysis
- skill detection
- unknown skill review
- company matching
- cover-letter draft context
- application package context

## Example Identity

- Person: Alex Beispiel
- Company: Example Technologies GmbH
- Role: IT Project Coordinator

Do not replace these examples with real CVs, certificates, application letters
or private company notes.
